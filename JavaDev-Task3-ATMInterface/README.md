# ATM Interface

## Project Description

A console-based ATM Interface developed using Java and Object-Oriented Programming concepts. The application simulates basic ATM operations such as user authentication, balance checking, deposits, withdrawals, and transaction management.

## Features

- User ID and PIN authentication
- Maximum of 3 incorrect login attempts
- Account balance checking
- Cash deposit
- Cash withdrawal
- Transaction management
- ATM menu-driven interface
- Secure PIN-based authentication
- Exit option

## Technologies Used

- Java
- Object-Oriented Programming
- VS Code

## How to Run

1. Open the project in VS Code.
2. Open the `src` folder.
3. Compile the Java files.
4. Run `Main.java`.
5. Enter the required User ID and PIN.
6. Select an option from the ATM menu.
